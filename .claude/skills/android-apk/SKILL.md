# Build and inspect an Android APK locally

The APK produced here is signed with the Android **debug** key: it is only for checking that
the native build works. Store builds are made by EAS Build from CI — never
try to run `eas build` yourself.

## 1. Android SDK

```bash
export ANDROID_HOME="$HOME/android-sdk"
[ -x "$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" ] || scripts/setup-android-sdk.sh
```

The script pins cmdline-tools 22.0 (classic `sdkmanager`) and installs platform-tools,
platform 36, build-tools 36.0.0 and 35.0.0, NDK 27.1.12297006 and CMake 3.22.1 (the versions
React Native 0.86 / Expo SDK 57 / Breez expect). Gradle downloads anything else it needs. JDK 17+ is required
(`java -version`).

## 2. Build

```bash
npm run build:android:local -- production              # or staging
ANDROID_ABIS=arm64-v8a npm run build:android:local -- staging   # faster: one ABI
```

It runs `expo prebuild --clean` for that variant (regenerates `android/`, gitignored) then
`./gradlew assembleRelease`, and copies the APK to `build/sattle-me-<variant>-<version>.apk`.
A full 4-ABI build compiles C++ for each ABI (10-30 min in a 4-CPU container). Tool-managed
background commands get killed after a time limit: start it detached
(`setsid nohup npm run build:android:local -- production > build.log 2>&1 &`) and watch the log.

**`APP_VARIANT` must be set for Gradle too**, not only for `expo prebuild`: Gradle re-evaluates
`app.config.ts` to embed `assets/app.config` (read by expo-constants) and the JS bundle. Running
`./gradlew` by hand without it silently embeds the _staging_ config (the default) into the APK. The
script exports it for both steps; if you re-run Gradle alone, export it yourself.

### Network failures in cloud containers

- `Received status code 429 from server: Too Many Requests` from `repo.maven.apache.org`:
  the container's shared egress IP is rate-limited by Maven Central. Install the mirror init
  script **on the machine only** (not in the project):
  `mkdir -p ~/.gradle/init.d && cp .claude/skills/android-apk/maven-central-mirror.gradle ~/.gradle/init.d/`
- `Could not parse POM` / `Could not resolve plugin` with nothing else wrong: a transfer was
  cut. Re-run; Gradle caches what already succeeded.

### Gradle runs out of memory

`java.lang.OutOfMemoryError: Metaspace` (the build then hangs): the generated
`android/gradle.properties` caps the daemon at `-Xmx2048m -XX:MaxMetaspaceSize=512m`, which a
cold 4-ABI build can exceed in a container. Kill the Java processes **by PID**
(`for p in $(pgrep -x java); do kill $p; done` — `pkill -f <pattern>` also matches your own
shell), raise the limits **for the machine only** (`~/.gradle/gradle.properties` overrides the
project's), then rebuild. Append, never overwrite: that file may already hold other settings
(proxy, signing passwords); if it already sets `org.gradle.jvmargs`, edit that line instead:
`echo 'org.gradle.jvmargs=-Xmx4g -XX:MaxMetaspaceSize=1g' >> ~/.gradle/gradle.properties`

## 3. Inspect the APK

```bash
APK=build/sattle-me-production-3.0.0.apk
BT="$ANDROID_HOME/build-tools/36.0.0"
"$BT/aapt2" dump badging "$APK" | head -5               # package, versionCode, versionName, sdk levels
"$BT/aapt2" dump xmltree --file AndroidManifest.xml "$APK" | grep -A1 "expo.modules.updates"
unzip -l "$APK" | grep -E "libbreez_sdk_spark_bindings|libbreeztech-breez"   # Breez libs, 2 per ABI
"$BT/apksigner" verify --print-certs "$APK" | head -3   # debug certificate expected locally
unzip -p "$APK" assets/app.config | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>{const c=JSON.parse(s);console.log(c.name,c.extra.appVariant,JSON.stringify(c.updates))})"
```

Expected invariants:

- production: package `ch.swissbitcoinpay.checkout`, `expo.modules.updates.ENABLED=false`,
  no `expo.modules.updates.EXPO_UPDATE_URL`, embedded `app.config` named "sattle.me"
  with `appVariant` `production` and `updates` `{"enabled":false}`;
- staging: package `ch.swissbitcoinpay.checkout.staging`, updates enabled, update URL
  `https://u.expo.dev/2a9acf4d-b234-4e38-8cbc-def87ce06491`, channel header `staging`, embedded
  `app.config` also named "sattle.me" (both variants share the name: only `appVariant`
  and the dark icon tell them apart).

When done, `rm -rf android` if you no longer need it (it is regenerated by every build). After a
production build it is required before `npm run android`: `expo run:android` only runs prebuild
when `android/` is missing, so it would reuse the production native project (application id
`ch.swissbitcoinpay.checkout`, updates disabled).
